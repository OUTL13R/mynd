# mynd

mynd is an open-source, local-first knowledge management app for building a
personal second brain. Inspired by tools such as Obsidian, it is designed to
help people capture notes, connect ideas, and turn their knowledge into a
useful, searchable workspace.

The desktop application is being built with Tauri, combining a lightweight
native experience with a modern web interface. Alongside familiar knowledge
management features, mynd will explore practical AI integrations that can help
users organize, search, summarize, and work with their own notes while keeping
them in control of their data.

This project is developed in the open and welcomes contributions, ideas, and
feedback from the community.
